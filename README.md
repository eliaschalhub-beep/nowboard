# Nowboard

A rolling 7-day personal dashboard: tasks and deadlines swept from mail and
messages, key dates, holidays, sport, and weather/travel disruption — one view,
always current.

- Site: https://nowboard.netlify.app
- Front end: built in Claude Design
- Data feed: `data/nowboard.json`, refreshed on a schedule

## Layout

    index.html          front end (Claude Design)
    data/nowboard.json  the feed the page reads
